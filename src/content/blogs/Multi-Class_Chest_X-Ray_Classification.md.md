
# Understanding CNNs for Image Classification

Convolutional Neural Networks (CNNs) are deep-learning models
commonly used to analyze images.

## What is a CNN?

A CNN learns spatial patterns from images using convolutional
filters. Early layers often learn simple patterns, while deeper
layers can learn more complex features.

## Main components

- **Convolution:** Extracts image features.
- **Activation:** Introduces non-linearity.
- **Pooling:** Reduces spatial dimensions.
- **Fully connected layers:** Help produce predictions.

## Why use CNNs?

CNNs are useful for image classification, object detection,
medical image analysis, and many computer-vision tasks.
